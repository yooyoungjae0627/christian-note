# 실시간 강의 받아쓰기

규칙은 이 파일에 적지 않는다. **`docs/policy/실시간_강의받아쓰기_지침.md`를 읽고 그대로 따른다.**

- 인자 `시작` → 지침 §2, `반영`(또는 인자 없이 받아쓴 글이 붙여 넣어짐) → §3, `끝` → §4.
- 인자가 없고 진행 중인 `첫열매들 강의 정리/원본/*/받아쓰기_상태.md`가 있으면 `반영`, 없으면 `시작`.
- 책 내용·모양은 지침이 가리키는 시리즈 지침과 README §3을 따른다.
