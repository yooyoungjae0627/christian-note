집필·디자인 규칙의 원본은 [창세기 교재 제작지침](../docs/policy/창세기_교재_제작지침.md)이다. 한영 성경 본문은 표준킹제임스성경의 글자 그대로 수록했다. 각 권에는 본문 해설, 요약 20항목, 문제 25개와 답안·근거, 예상 질문 12개, 용어와 참고 자료가 있다.

## 출처와 영상 이동

해설에 사용한 강의명, PDF 파일명과 실제 PDF 쪽수를 적었다. 출처에 기존 구간 링크가 있을 때 PDF는 클릭 링크와 QR, EPUB은 클릭 링크를 제공한다. 구간 주소가 없는 PDF도 해설 근거로 사용하고 쪽수를 표기한다. 존재하지 않는 주소·시각을 만들지 않는다.

연결은 교회 PDF에 실린 구간 주소의 재사용이다. 영상에서 문장 시작 시점을 새로 측정하거나 영상 재생·접근 가능 여부를 검사하지 않았다. 관련 여러 쪽을 합쳐 설명한 항목은 그 사실을 출처 기록에 남겼다.

## 자료 검토

[전체 검토 기록](자료검토/검토보고.md): Theme 33권과 Milk 11권, 3,166쪽의 본문·링크를 추출하고 권별 요약과 원고 대조를 검토했다. 모든 페이지를 그림으로 보거나 문장마다 정독했다고 의미하지 않는다. 집필에 사용한 근거 쪽은 장별 원본 JSON에 따로 기록했다.

바탕화면의 기존 1–3장 해설에서 추출한 해설 121문단을 사용했다. 밀크 9-2강 PDF 62쪽과 대조해 ‘아브라함 이전은 주의 날 1’이라는 기존 문장을 ‘주의 날 2’로 바로잡았고 [수정 기록](원본/corrections.json)에 이유를 남겼다.

## 기준 PDF 스타일 반영 — 2026-10-10

바탕화면의 `창세기_1-3장_해설.pdf`에서 글꼴, 크기, 자간, 줄 간격, 좌우 여백, 제목과 본문 상자 및 강조 범위를 추출했다. 본문은 Noto Serif KR 10.3pt, 제목은 Noto Sans KR을 사용한다. 원본의 121개 해설 문단에서 강조 배경 230곳을 옮겼다. 첫 해설 문단의 줄바꿈이 같고 다섯 줄의 세로 위치 차이는 1pt 이내다. 출처·QR과 학습 자료가 추가되어 원본 합본과 페이지 수 및 뒤쪽 문단의 위치는 다르다. 표지의 나무 그림은 같은 구성으로 다시 그렸다.

EPUB은 PDF 페이지 그림과 같은 위치의 클릭 영역을 사용해 글꼴·배경·배치를 유지한다. 페이지별 본문 전사도 포함한다. 글자 크기를 바꾸어 재배치하는 텍스트형 EPUB은 아니다.
