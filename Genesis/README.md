# 창세기 이야기 단원별 해설서

성도 유영재 교재. 창세기 1–50장을 이야기 단원 30권으로 나눴다(천지창조 → 아담과 이브 → 카인과 아벨 → …). 단원마다 PDF와 고정 배치 EPUB을 한 권씩 냈다. 2026-10-23 제작. 2026-10-12에 만든 장별 책 50권은 이때 저장소에서 뺐다.

- 규칙: [장별 해설서 제작지침(2판) §0-1](../docs/policy/장별해설서_제작지침.md) · 근거 순위: [성경 해석 지침](../docs/policy/성경해석_지침.md)
- 원고: 해설·칠판·인물·지도는 [원본/2판/](원본/2판/) `chapterNN.json`(장별 원고)에 있다. 단원 목록은 [원본/단원/units.json](원본/단원/units.json)이고, 단원 원고 `unitNN.json`에는 제목·표지·표어·학습 자료가 있다.
- 다시 만들기: `node tools/chapterbook/check.mjs genesis all` → `node tools/chapterbook/units.mjs check` → `node tools/chapterbook/build.mjs genesis unit 1 2 …` → `node tools/chapterbook/verify.mjs genesis unit 1 2 …`
