# Christian Note

첫열매들(FIRSTFRUITS) 교회의 강의를 바탕으로 **성도 유영재**가 성경 공부 교재를 집필·관리하는 저장소입니다.
교재는 **강의 하나 = 책 한 권**이고, 책마다 **PDF와 EPUB을 항상 함께** 냅니다.

---

## 🤖 AI 에이전트에게 — 집필 전에 반드시

이 저장소에서 교재를 쓰거나 고치는 모든 AI 에이전트는 아래 순서를 지킵니다.

### 1. 필수 근간 문서 두 개를 먼저 읽는다
모든 집필은 이 두 문서를 **근간**으로 합니다. 다른 어떤 문서·일반 지식보다 앞섭니다.

| # | 문서 | 위치 | 역할 |
|---|---|---|---|
| ① | **밀크 교리 정리** | `docs/core/` (사용자가 올리는 밀크 정리 md) | 첫열매들 교리의 중심. 모든 내용의 옳고 그름을 이 문서로 판단한다 |
| ② | **교재 집필 정책** | `docs/core/` (사용자가 올리는 집필 정책 md) | 세 시리즈에 공통인 집필 원칙 |

- `docs/core/`에 아직 문서가 없으면 임시로 ① = `docs/doctrine/00_교리_총정리.md`(+ 강별 `docs/doctrine/milkNN.md`), ② = `docs/policy/밀크교재_제작지침_1_전체판.md`를 근간으로 삼습니다.
- `docs/core/`의 문서와 다른 문서가 어긋나면 **`docs/core/`가 우선**합니다. 시리즈 지침을 그에 맞게 고치고 이유를 내력 표에 남깁니다.

### 2. 명령에 맞는 시리즈 지침을 읽는다 (라우팅)

| 이런 명령을 받으면 | 시리즈 | 읽을 지침 (단일 원본) | 작업 원본 | 완성본 |
|---|---|---|---|---|
| 「다윗의 삶」, 다윗 시리즈 설교 강의, 사무엘기 영어 | **David** | `docs/policy/다윗의삶_교재_제작지침.md` | `David/원본/` | `David/다윗의_삶_NN강_말씀판.pdf·.epub`, 영어 별권 `다윗의_삶_영어로읽는사무엘기.pdf·.epub` |
| 밀크(MILK) 강의, 「하나님 말씀의 기초원리」 N강 | **Milk** | `docs/policy/밀크교재_제작지침_1_전체판.md` (+ 말씀판 `_2_말씀판.md`) | (PDF가 원본) | `Milk/<제목>_밀크N강.pdf·.epub` |
| 첫열매들 예배 강의, "주제별 교재", 새 예배 주제 | **Theme** | `docs/policy/성경주제별_교재_제작지침.md` (+ 밀크 ①) | `Theme/원본/` | `Theme/NN_이름.pdf·.epub` |
| 주간 성경 구절 테스트 카드 | cards | `docs/policy/성경구절_테스트카드_제작정책.md` | — | `cards/*.html` |

각 시리즈 폴더의 `POLICY.md`는 이 표와 같은 안내(어느 지침을 읽고 무엇을 실행하는지)를 그 폴더 안에서 다시 보여 줍니다. **규칙 본문은 `docs/policy/`의 지침 한 곳에만** 적습니다(두 곳에 적으면 어긋납니다).

### 3. 세 시리즈 공통 원칙
- **강의 1개 = 책 1권.** 새 강의를 받으면 새 책을 만들고, 그 책만 빌드합니다. 강의를 한 권에 합치지 않습니다(2026-10-09).
- **PDF + EPUB 둘 다** 만들고 둘 다 검사합니다. 하나만 고치지 않습니다.
- **내용은 강의(녹취록·슬라이드)와 교회 교재에서만.** 일반 신학 지식으로 보충·수정·반박하지 않습니다. 교회 교리가 주류 교단과 달라도 그대로 따릅니다.
- **성경 본문은 토씨 하나 바꾸지 않습니다.** 슬라이드 글자·사용자가 올려준 본문이 있으면 그 글자 그대로(출처도 슬라이드 표기 그대로).
- **기본 역본 = 표준킹제임스성경**(사용자 지시 2026-10-10). 별다른 명령이 없으면 구절을 직접 찾아 넣는 모든 곳(슬라이드 없는 강의의 그림·말씀 상자, 강의에서 언급만 한 구절, 해설서 본문 등)은 [kingjamesbiblekorea.com/parallel](https://kingjamesbiblekorea.com/parallel)에서 그 구절을 찾아 **번역문을 글자 그대로** 씁니다. 출처 끝에 `· 표준킹제임스성경`. 도구: `node tools/kjv.mjs "창세기 1:1-5"`(`--en` 영어 KJV 함께, `--json`). 한글KJV(hangl.net)는 더 쓰지 않습니다(이미 만든 책은 그대로 둠).
- **지어내지 않습니다.** 없는 구절·슬라이드·제목은 요청합니다. 유튜브 링크를 받지 않은 강의는 영상 이동(QR·▶)을 넣지 않습니다.
- **검증 없이 완료 보고 금지.** 검사 스크립트를 실제로 돌리고 exit code와 수치를 보고합니다.
- 빌드 산출물(`node_modules/`, `out/` 등)은 커밋하지 않습니다. 완성본 PDF·EPUB만 커밋합니다.

## 폴더 구조

```
README.md            ← 이 문서(AI 라우팅)
CLAUDE.md, AGENTS.md ← 에이전트 세션 시작 안내(같은 내용)
docs/
  core/              ← ★ 필수 근간: 밀크 교리 정리 md, 교재 집필 정책 md (사용자가 올림)
  doctrine/          ← 교리 총정리와 밀크 강별 교리
  policy/            ← 시리즈별 제작 지침(단일 원본)
David/   POLICY.md, 원본/(원고·도구), 완성본 PDF·EPUB
Milk/    POLICY.md, 완성본 PDF·EPUB
Theme/   POLICY.md, 원본/(이야기별 원고·그림·도구), 완성본 PDF·EPUB
cards/   주간 구절 테스트 카드 HTML
source_text/  밀크 교재 PDF에서 뽑은 글자(검색용)
tools/   시리즈 공통 도구(kjv.mjs 표준킹제임스성경 구절 찾기, pdf2epub.mjs, check_epub.mjs)
```

## 빌드 환경 메모
- Windows, Node + Microsoft Edge 명령줄 인쇄. Python 없음.
- node_modules는 저장소·OneDrive 밖의 임시 폴더에 설치하고 도구를 복사해 실행합니다(`tools/package.json` 참고).
- Edge는 Claude Code 샌드박스 안에서 바로 종료되므로 빌드는 샌드박스 밖에서 실행합니다.
