# 첫열매들 성경 해석 챗봇 (카카오톡)

성도가 카카오톡으로 성경·교리를 물으면, 이 저장소에 모아 둔 첫열매들 강의와 교리 정리에서 찾아 **강의 제목·분:초 링크와 함께** 답하는 챗봇 서버입니다.

- **규칙은 새로 만들지 않았습니다.** 답하는 순서와 근거의 순위는 [`docs/policy/성경해석_지침.md`](../docs/policy/성경해석_지침.md), 옳고 그름의 기준은 [`docs/doctrine/00_교리_총정리.md`](../docs/doctrine/00_교리_총정리.md)입니다. 서버가 켜질 때 두 문서(와 `memory-bank/이단_판정/`)를 **그대로 읽어** AI에게 줍니다. 문서를 고치고 서버를 다시 켜면 챗봇도 바뀝니다.
- **AI를 다시 학습시키는 방식(파인튜닝)이 아닙니다.** Claude가 질문마다 저장소 자료를 검색해 읽고 답합니다. 그래서 새 강의 스크립트를 `memory-bank/`에 넣고 서버를 다시 켜기만 하면 그 강의도 답에 쓰이고, 답마다 출처를 확인할 수 있습니다.

## 구조

```
카카오톡 ──(스킬 요청)──▶ src/server.mjs ─▶ src/app.mjs   인증·하루 횟수·「답 보기」·콜백
                                              │
                                              ▼
                                        src/agent.mjs      Claude + 도구 두 개
                                         ├─ search     →  src/search.mjs (저장소 자료 낱말 검색)
                                         └─ get_verse  →  tools/kjv.mjs (표준킹제임스성경 본문 글자 그대로)
```

| 파일 | 하는 일 |
|---|---|
| `src/corpus.mjs` | 자료를 읽어 검색 조각으로 나눔 — 교리(`docs/doctrine/`), 1순위(`memory-bank/첫열매들_강의스크립트/`), 2순위(`memory-bank/세대주의_해설/scofield/`), 3순위(`사무엘상·하/강의스크립트/`, `이이레 목사 성경 해석/원본/*/transcript_raw.txt`) |
| `src/search.mjs` | 낱말 검색(BM25, 한글 두 글자 단위). 외부 서비스·키 없이 서버 안에서 돈다 |
| `src/prompt.mjs` | 시스템 프롬프트(지침·교리 문서 원문 + 카카오톡 답 형식) |
| `src/agent.mjs` | Claude API 호출과 도구 루프 |
| `src/kakao.mjs` | 카카오 스킬 응답 형식(말풍선 1,000자·3개 제한에 맞춰 자름, 마크다운 제거) |
| `src/app.mjs` | 요청 처리 흐름 |
| `cli.mjs` | 카카오톡 없이 터미널에서 시험 |
| `test/` | 테스트(키·네트워크 없이 돈다) |

## 설치와 시험

Node 20 이상. Windows에서는 저장소가 OneDrive 안에 있으므로 다른 도구와 마찬가지로 `node_modules`를 저장소 안에 두지 않으려면 저장소를 OneDrive 밖에 따로 받아서 실행합니다(서버용 컴퓨터에서는 그냥 받으면 됩니다).

```bash
cd chatbot
npm install
npm test                                              # 테스트 7개
node cli.mjs --search 1순위 "징계 가시"                # 검색만 (키 없이)
ANTHROPIC_API_KEY=sk-ant-... node cli.mjs "징계와 가시는 어떻게 다른가요?"   # AI 답 (말풍선 모양으로 출력)
```

## 서버 실행

```bash
ANTHROPIC_API_KEY=sk-ant-... \
CHATBOT_ACCESS_CODE=교회에서_나눠줄_번호 \
CHATBOT_SKILL_SECRET=아무도_모르는_긴_글자 \
node chatbot/src/server.mjs
```

| 환경 변수 | 뜻 | 기본값 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키(console.anthropic.com). **없으면 AI 없이 관련 강의 대목과 링크만 보여 줍니다.** 키는 저장소에 올리지 않습니다 | 없음 |
| `CHATBOT_ACCESS_CODE` | 성도 인증 번호. 성도가 처음 한 번 `인증 번호`라고 보내면 그 뒤로 계속 쓸 수 있습니다. 비우면 채널을 추가한 누구나 씁니다 | 없음(누구나) |
| `CHATBOT_SKILL_SECRET` | 카카오 스킬 헤더 `x-skill-secret`와 맞춰 보는 값. 카카오가 아닌 곳에서 서버 주소로 직접 보내는 요청을 막습니다 | 없음(검사 안 함) |
| `CHATBOT_DAILY_LIMIT` | 한 사람이 하루에 할 수 있는 질문 수(비용 보호) | 30 |
| `CHATBOT_MODEL` | Claude 모델 | `claude-opus-5-5` |
| `CHATBOT_EFFORT` | 생각하는 깊이(`low`·`medium`·`high`). 높이면 느려져 카카오톡 시한을 넘기기 쉽습니다 | `low` |
| `CHATBOT_DATA_DIR` | 인증한 사용자 목록을 두는 폴더(저장소 밖) | 임시 폴더 |
| `PORT` | 포트 | 8787 |

서버는 인터넷에서 **https 주소**로 열려 있어야 하고(카카오가 호출합니다), 이 저장소 전체를 받아 둔 곳에서 실행합니다. 자료를 새로 넣었으면 `git pull` 뒤 서버를 다시 켭니다. `get_verse`는 `kingjamesbiblekorea.com`에 접속하므로 서버에서 그 사이트로 나가는 접속이 열려 있어야 합니다.

## 카카오톡 연결 (카카오 i 오픈빌더)

카카오 화면의 메뉴 이름은 바뀔 수 있으니 흐름으로 봐 주세요.

1. **카카오톡 채널**을 만든다(카카오톡 채널 관리자센터).
2. **챗봇 관리자센터**(카카오비즈니스)에서 봇을 만들고 그 채널에 연결한다.
3. **스킬**을 만든다 — URL `https://<서버 주소>/kakao/skill`, 헤더 `x-skill-secret: <CHATBOT_SKILL_SECRET 값>`.
4. **폴백 블록**(어떤 말에도 걸리지 않을 때 실행되는 블록)에 그 스킬을 연결하고, 봇 응답을 「스킬데이터 사용」으로 둔다. 이렇게 하면 성도가 보내는 모든 말이 이 서버로 옵니다.
5. **AI 챗봇 콜백**을 신청한다(봇 설정의 「AI 챗봇 관리」). 승인되면 폴백 블록에서 「콜백 설정」을 켠다.
   - 카카오톡은 스킬 서버가 **5초 안에** 답해야 하는데 AI 답은 보통 10~40초 걸립니다. 콜백을 켜면 서버가 먼저 "찾고 있습니다"를 보내고 1분 안에 답을 따로 보냅니다.
   - **콜백이 없어도 동작합니다.** 그때는 "20초쯤 뒤에 「답 보기」를 눌러 주세요"라는 버튼이 나가고, 성도가 누르면 다 된 답을 돌려줍니다. 승인을 기다리는 동안은 이 방식으로 쓰면 됩니다.
6. 봇을 **배포**한다.

성도가 쓰는 말: 그냥 질문 / `인증 번호` / `답 보기` / `도움말`.

## 알아 둘 것

- **검수.** AI가 정리한 답입니다. 강의에 없는 말을 지어내지 않도록 자료 검색·출처 링크·"없으면 없다고 말한다"를 지침대로 걸어 두었지만, 성도들에게 열기 전에 자주 나올 질문 20~30개를 `cli.mjs`로 돌려 보고 답을 검수하는 것을 권합니다. 도움말에도 "비공식 도우미, 링크의 강의 원문으로 확인"이라고 나갑니다.
- **교회의 허락.** 강의 영상과 교재의 저작권은 교회에 있습니다. 성도들에게 나누기 전에 교회에 알리고 허락을 받는 것이 좋습니다.
- **비용.** 질문마다 Claude API 요금이 듭니다(교리 총정리가 매번 들어가지만 캐시되어 싸게 읽힙니다). 실제 토큰 수는 서버 기록의 `답 …ms · 입력 … · 출력 …` 줄에서 볼 수 있으니, 처음 며칠 지켜보고 `CHATBOT_DAILY_LIMIT`과 `CHATBOT_MODEL`을 정하세요.
- **개인 정보.** 질문 글은 답을 만들기 위해 Claude API(Anthropic)로 보내집니다. 서버 기록에는 질문 글을 남기지 않고 토큰 수만 남깁니다. 대화는 30분 동안 최근 세 번의 문답만 메모리에 두었다가 버립니다(이어지는 질문을 알아듣기 위해).
- **검색의 한계.** 자동 자막이라 오인식이 있고, 낱말이 겹치는 정도로 찾습니다. AI가 낱말을 바꿔 가며 여러 번 찾도록 했지만 못 찾는 대목이 있을 수 있습니다. 그때는 "찾지 못했다"고 답합니다.
- **2순위.** 저장소에 보관된 스코필드 관주 해설(영어 원문)만 씁니다. 무디·라킨·럭크만은 보관본이 없어 인용하지 않습니다.
- **아직 안 넣은 자료.** 밀크 교재 원문(`source_text/`)과 완성된 교재 원고는 검색에 넣지 않았습니다(교리 정리와 강의 스크립트가 같은 내용의 원본이라서). 필요하면 `src/corpus.mjs`에 더하면 됩니다.
