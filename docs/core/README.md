# docs/core — 필수 근간 문서

이 폴더에는 사용자(성도 유영재)가 직접 올리는 두 문서가 들어옵니다.

1. **밀크 교리 정리 md** — 첫열매들 교리의 중심
2. **교재 집필 정책 md** — 세 시리즈 공통 집필 원칙

모든 교재 집필은 이 두 문서를 근간으로 합니다(저장소 첫 화면 `README.md` §1).
두 문서가 올라오기 전에는 `docs/doctrine/00_교리_총정리.md`와 `docs/policy/밀크교재_제작지침_1_전체판.md`를 임시 근간으로 씁니다.
문서가 올라오면 시리즈 지침(`docs/policy/`)과 어긋나는 곳을 찾아 지침 쪽을 고치고, 각 지침의 내력 표에 남깁니다.
