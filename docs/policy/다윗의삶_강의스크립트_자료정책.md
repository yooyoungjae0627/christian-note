## 2. 교재에 쓰는 법

1. **내용은 스크립트에 있는 강사의 설명만 쓴다.** 일반 신학으로 보충·수정·반박하지 않는다(README §3). 스크립트에 없는 해설은 지어내지 않는다.
2. **퇴고는 교재 원고에서 한다.** 음성 인식 오류는 문맥으로 바로잡아 원고에 쓰되, 고친 낱말은 보고한다(예: 사계상·기상·사기상 → 사무엘기상, 사무엘기아 → 사무엘기하, 언약계 → 언약궤). 뜻이 불분명한 대목은 추측해 메우지 않고 영상을 확인하거나 빼고 보고한다.
3. **근거를 남긴다.** 교재 문단마다 근거로 쓴 스크립트 파일과 시각, 그 줄의 원문(오인식 포함 그대로)을 원고 JSON 등에 보존한다.
4. **영상 이동(QR·▶)은 스크립트의 시각 링크를 쓴다.** 문단의 근거가 시작되는 줄의 시각 링크를 그대로 쓴다. 새 시각을 만들거나 몇 초를 빼는 등의 보정을 하지 않는다. 영상을 재생해 발언 시점을 다시 확인하지 않았다면 확인했다고 쓰지 않는다.
5. **성경 본문은 스크립트에서 옮기지 않는다.** 강사가 읽은 구절은 자막이 부정확하므로, 교재의 구절은 해당 시리즈 지침의 역본(기본: 표준킹제임스성경 `node tools/kjv.mjs`)에서 글자 그대로 가져온다.
6. **본문 장과 강의 장을 구분한다.** 어떤 장의 교재에 다른 장 강의의 언급을 쓸 때는 "N편(본문 ○장) 강의에서 이 절을 인용하며 한 설명"처럼 출처의 맥락을 함께 적는다.
7. 「다윗의 삶」 본책(`docs/policy/다윗의삶_교재_제작지침.md`)의 `원본/NN강/transcript_raw.txt`는 이 스크립트에서 해당 편을 옮겨 만들 수 있다. 강 번호와 영상ID가 서로 맞는지 반드시 확인한다(§4).

## 3. 영상 검토

- 영상·구간을 브라우저로 열어 확인할 때는 **작업용 브라우저 탭만** 음소거하거나 일시정지한다. 사용자가 화면에서 따로 재생하는 소리는 건드리지 않는다(사용자 지시 2026-10-11).
- 스크립트를 다시 수집할 때는 영상 페이지의 「스크립트 표시」 패널에서 시각과 글자를 그대로 복사한다. 편 수·줄 수를 이 문서와 `사무엘상·하/README.md`에 갱신한다.
