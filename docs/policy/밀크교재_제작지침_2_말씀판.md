# 밀크 강의 교재 제작 지침 ② 말씀판 (PT 이미지 없는 판)

전체판(지침 ①)과 원고·디자인·쪽 나눔 정책은 같습니다. **다른 점만** 아래에 적습니다. 나머지는 지침 ①을 그대로 따릅니다.

---

## 1. 이 판의 목적
- 강의 PT 이미지 대신 **그 슬라이드의 성경 구절을 글로 적어** 본문에 넣습니다.
- 인쇄 분량·잉크를 줄이고, 말씀 자체에 집중해 읽고 필기하기 좋게 합니다.
- 파일 이름: `<제목>_밀크N강_말씀판.pdf`

## 2. 슬라이드 → 말씀 상자
- 슬라이드 이미지는 **한 장도 넣지 않습니다.** 슬라이드가 나오던 바로 그 자리에 **말씀 상자**를 둡니다.
- 말씀 상자 내용
  - 머리: 슬라이드 제목(있으면). 예: "초실절", "상속자의 조건"
  - 본문: 슬라이드에 보이는 구절을 **글자 그대로** 옮깁니다(…생략 표시, 괄호 속 설명도 그대로). 슬라이드에 없는 구절을 지어내거나 늘리지 않습니다. 가려진 글자는 성경 본문으로 채우고 알립니다.
  - 출처: 오른쪽 아래. 예: 레위기 23:10-11 (한킹)
- **말씀 상자 안에도 3단계 강조**를 넣습니다.
  - 중요 → **노란 바탕**
  - 더 중요 → **노란 바탕 + 굵게**
  - 가장 중요 → **노란 바탕 + 굵게 + 빨간 밑줄**
  - 기준: 슬라이드에서 색으로 칠해진 낱말과, 강사가 강의에서 짚은 부분을 먼저 표시합니다. 한 상자에 1~3곳, 3단계는 그 강의의 핵심 명제와 맞닿은 구절에만.
- 구절이 없는 슬라이드
  - 도식·그림 → **그림 설명 상자**(연한 파랑): 화면의 글자와 표시를 그대로 옮겨 1~3줄로 설명.
    예: "흙의 몸(의인 혼·성령) → 저주의 몸(죄인 혼·영) — 선악과를 먹은 뒤 몸과 혼이 바뀌고 성령이 떠남"
  - 표·연표 → 표로 옮깁니다.
  - 강의 표지·제목 화면 → 넣지 않습니다.
- 같은 구절이 연달아 두 번 나오는 단계 화면은 한 번만 적고, 바뀐 점은 그림 설명 상자로 덧붙입니다.

## 3. 구성 (전체판과 다른 점)
- 순서: 표지 → 들어가며 → 이 책을 읽는 법 → 차례 → 시작하며 → 본문 장들 → 마치며 → **한눈에 보는 오늘 이야기 → 용어·인물 풀이**
- **개념 문제, 답안, 예상 질문과 답변은 넣지 않습니다.**
- 이 책을 읽는 법: '강의 그림의 색깔' 표는 그림 설명 상자에 색 이름이 나올 때만 둡니다. 책의 구성 문구를 이 판에 맞게 바꾸고, "강의 슬라이드는 그림 대신 그 구절을 글로 옮겨 실었습니다"를 한 줄 넣습니다.
- 표지 하단 문구, 들어가며, 고린도전서 3:11-15 상자는 전체판과 같습니다. 표지 위쪽에 '말씀판'을 작게 표시합니다.

## 4. 영상 표시
- 전체판과 같은 3판 규칙(QR코드판 / 유튜브아이콘판 / 클린판)을 따릅니다. 위치는 장 제목·소제목 옆뿐입니다(답안·예상 질문이 없으므로).
- 따로 말씀이 없으면 QR코드판을 기본으로 만듭니다.

## 5. 쪽 나눔
- 전체판과 같습니다: 앞부분·뒷부분 섹션은 새 쪽에서 시작하고, 본문 장은 이어서 흐릅니다.
- **말씀 상자와 그 앞뒤 맥락은 떨어지지 않게**: 상자의 머리·본문·출처는 한 덩어리로 둡니다. 상자를 소개하는 문장("읽어 보겠습니다" 등)과 상자는 같은 쪽에 둡니다. 한 쪽보다 긴 상자만 이어지는 것을 허용하고 알립니다.

## 6. 검사
- 원고가 빠짐없이 순서대로 들어갔는지, 강조 표시 짝이 맞는지(말씀 상자 포함)
- 모든 슬라이드가 말씀 상자·그림 설명·표 중 하나로 들어갔는지(표지 화면 제외)
- 이미지 0장, '개념 문제'·'예상 질문' 글자 없음
- 영상 링크 검사(전체판과 같음)

## 7. 저장·전달
- 바탕화면에 `<제목>_밀크N강_말씀판.pdf`로 저장합니다. 시리즈 묶음이면 `밀크시리즈_교재\4_말씀판` 폴더에 넣습니다.
- 보고: 쪽수, 말씀 상자 수, 그림 설명 상자 수, 넣지 않은 화면(표지 등), 채운 글자.
