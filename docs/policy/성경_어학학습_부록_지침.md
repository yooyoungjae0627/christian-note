# 성경 어학 학습 부록 지침 — 영어·일본어 독해·회화

> 사용자 지시 2026-11-21: 「창세기_24_포티팔의_집과_감옥 … 이 구절 내에서 영어 회화, 영어 독해, 일본어 회화, 일본어 독해를 공부하고 싶다」「기존 컨텐츠 끝나고 맨 뒤에 추가」「교재를 만드는 거다」「나는 일본어 아예 모른다」「소리까지 적어 줘야 해 한국말로」.
> 단원 책(장별해설서 지침 §0-1)에 붙는 **선택 부록**이다. 원고가 있는 단원만 붙는다. 처음 적용: 창세기 24단원 → 2026-11-21 창세기 30단원 전부(레슨 285개, 일본어 본문 1–50장).

## 1. 자리와 범위
- 책의 **맨 뒤**, 「참고한 자료」 다음에 둔다. 앞의 교재 내용(표지 … 참고한 자료)은 바꾸지 않는다.
- 다루는 글은 **그 단원의 성경 범위 안**에서만 고른다(예: 24단원은 창세기 39:1–40:23).
- 레슨은 그 책의 단락(`sections`)과 1:1로 맞춘다. 레슨 제목·절 범위는 단락과 같다.
- 교리 해설은 넣지 않는다. 어학 부록은 말과 글을 익히는 곳이다.

## 2. 레슨 하나의 구성(4트랙)
1. **영어 독해** — 그 단락의 현대 영어(WEB) 한 절을 **글자 그대로** 싣고, 끊어 읽기(영어 조각 · 한글 소리 · 뜻)와 문법 한 가지를 단다.
2. **영어 회화** — 그 단락 장면을 오늘의 상황으로 옮긴 연습 대화 4–6줄(영어 · 한글 소리 · 뜻)과 핵심 표현.
3. **일본어 독해** — 일본어 성경 한 절을 **글자 그대로** 싣고, 한자 위에 후리가나, 끊어 읽기(일본어 조각 · 한글 소리 · 뜻), 단어를 단다.
4. **일본어 회화** — 짧은 연습 대화 3–4줄(일본어 · 한글 소리 · 뜻)과 핵심 표현.

5. **⑤ 정리 — 구문·문법·단어**(사용자 지시 2026-11-21 「구문과 문법 그리고 단어 정리도 추가」) — 영어·일본어 각각 구문 1–3개(구문 + 새 예문 · 한글 소리 · 뜻), 문법 요약(①③의 문법 이름과 첫 문장), 단어 4–8개(품사·한글 소리·뜻). 단어는 **그 레슨의 본문·대화에 실제로 나온 말**만(활용형이면 `from`에 본문 꼴). 예문은 연습용으로 지은 문장이다.
- 부록 맨 끝 **총정리**: 영어 단어장(알파벳순), 일본어 단어장(あいうえお순), 문법 색인, 구문 모음 — 레슨 정리를 모아 자동으로 만든다(새 내용 없음).

## 3. 본문(성경) — 글자 그대로
- 영어: World English Bible(British Edition, 퍼블릭 도메인) — 책의 칠판에 쓰는 `verses-<책>-web.json` 그대로.
- 일본어: **フリーダム・バイブル(Japanese Freedom Bible, 2026, 퍼블릭 도메인, ebible.org/jpnm)** — `창세기/원본/2판/verses-genesis-ja.json`. 口語訳은 저작권 논란(위키문헌 삭제 논의 중)이 있어, 新改訳·新共同訳 등은 저작권이 있어 쓰지 않는다.
- 후리가나는 원고에서 `漢字[かんじ]`로 적고, 괄호를 걷어 낸 글자가 본문과 같아야 한다(검사기).
- 끊어 읽기 조각을 차례로 이으면 본문 절과 같아야 한다(검사기).

## 4. 한글 소리
- 일본어를 **전혀 모르는 사람** 기준. 모든 일본어 줄과 단어에 한글 소리를 단다. 영어 대화·끊어 읽기에도 단다.
- 일본어 소리는 국립국어원 표기보다 **실제 들리는 소리**에 가깝게: 조사 は→「와」, へ→「에」, を→「오」, 장음은 「-」(예: しゅう → 슈-), っ→ㅅ 받침, ん→ㄴ 받침(뒤 소리에 따라 ㅁ·ㅇ으로 들려도 ㄴ으로 통일).
- 영어 소리는 강세 음절을 굵게 하지 않고, 이어 말할 때의 소리(연음)를 반영한다(예: Why do you → 와이 두 유).
- 한글 소리는 근사치라는 안내를 부록 첫 쪽에 둔다.
- 부록 첫머리에 **히라가나 소리표**(기본 46자 + 탁음·반탁음, 한글 소리)를 둔다.

## 5. 연습 대화
- 연습 대화는 본문이 아니라 **연습용으로 지은 대화**다. 레슨마다 「연습용 대화 — 성경 본문이 아님」을 표시한다.
- 그 단락 장면에서 출발하되 오늘 생활에서 쓸 수 있는 말로 바꾼다. 성경 인물의 말이나 교회 교리를 지어내지 않는다.

## 6. 원고와 검사
- 원고: `창세기/원본/단원/genesis-langNN.json`. 형식·검사는 `tools/chapterbook/lang.mjs` 머리 주석.
- `node tools/chapterbook/lang.mjs genesis check NN` 종료 코드 0이어야 빌드에 붙는다(빌드가 같은 검사를 돌린다).

## 7. 소리 듣기(▶ 버튼·QR)
- 사용자 지시 2026-11-21 「원어민 읽어주는 버튼 삽입」 → 「방법 1로 해, GitHub Pages 켜도 돼」.
- PDF 안에 소리 파일을 넣지 않는다(대부분의 PDF 보기 앱이 재생하지 못함). 대신 문장마다 빨간 **▶ 링크**, 레슨 첫머리에 **QR**(휴대폰으로 이 레슨 듣기)을 둔다.
- ▶·QR은 듣기 페이지 `https://yooyoungjae0627.github.io/christian-note/listen/?b=<책>&u=<단원>&k=<칸 id>`를 연다. 페이지(`listen/index.html`)는 기기에 내장된 음성(Web Speech API)으로 읽는다 — 사람이 녹음한 소리가 아니라고 부록 안내와 페이지에 밝힌다. 유료 음성 서비스·비공식 음성 API는 쓰지 않는다.
- 칸 id: `<레슨>-er`(영어 본문), `-er-N`(끊어 읽기), `-et-N`(영어 대화), `-ek-N`(영어 표현), `-ep-N`(영어 구문 예문), `-ev-N`(영어 단어), `-jr`·`-jr-N`·`-jt-N`·`-jk-N`·`-jp-N`·`-jv-N`(일본어). 레슨 QR은 `k=<레슨>`.
- 데이터 `listen/data/<책>-<단원>.json`은 빌드가 원고에서 만든다(`lang.mjs` `exportLang`). 손으로 고치지 않는다. 일본어 음성 글은 원래 글(한자 섞임)로 읽히고, 읽기가 갈리는 한자(主·長)만 후리가나로 바꾼다.
- 배포: `.github/workflows/pages.yml`이 `listen/`만 GitHub Pages로 올린다(저장소 전체를 공개 사이트로 올리지 않음).
- 검사: `verify.mjs`가 듣기 링크 수를 세고, 레슨 QR을 실제로 판독해 링크 주소와 같은지 본다.
