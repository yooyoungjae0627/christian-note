# 성경 해석 지침 — 질문에 답할 때 근거의 순위

> 성경 해석(구절의 뜻, 교리, 인물·사건의 의미 등)을 묻는 질문에 답할 때 따르는 **단일 원본**이다.
> 2026-10-12 사용자(성도 유영재) 지시: "이게 우리 교회 지침이자 성경 해석의 기본이 될 것이다."

## 1. 근거의 순위

| 순위 | 근거 | 위치 | 답에 붙이는 출처 |
|---|---|---|---|
| **1순위** | **첫열매들 교회 영상 강의** (박진영) | `memory-bank/첫열매들_강의스크립트/` — 재생목록별 폴더, 한 편 = 한 파일, 줄마다 시각 링크 | 강의 제목 + **분:초** + 그 시각으로 바로 가는 링크 `https://youtu.be/<영상ID>?t=<초>` |
| **2순위** | **세대주의 해설가** — C. I. 스코필드, D. L. 무디, 클라렌스 라킨, 피터 럭크만 — 의 해설 중 **첫열매들 교리에 가까운 것** | (아직 저장소에 없음 — 답할 때마다 출처를 직접 확인) | 해설가 이름 · 책/주석 이름 · 장절 또는 쪽 · 확인한 주소(URL) |
| **3순위** | **서울침례교회 이이레 목사 강의** — 「다윗의 삶」 59편 ([재생목록](https://www.youtube.com/playlist?list=PLORD0HswpChCFTWTPwO-GZryn9hB617FY)) | `사무엘상·하/강의스크립트/` — 한 편 = 한 파일, 줄마다 시각 링크(2026-10-11 수집, 목록 `사무엘상·하/README.md`, 사용 규칙 `docs/policy/다윗의삶_강의스크립트_자료정책.md`) | 1순위와 같은 형식(제목 + 분:초 + 시각 링크) |

교리의 옳고 그름을 판단하는 기준은 여전히 **밀크 교리 정리**(README §1의 근간 문서 ①)다. 1순위 영상도 이 교리와 같은 교회의 가르침이며, 2·3순위는 이 교리에 맞는 범위에서만 쓴다.

## 2. 답하는 순서

1. **1순위부터 찾는다.** `memory-bank/첫열매들_강의스크립트/`에서 구절·낱말·주제를 검색한다(자동 자막이라 오인식이 있으므로 비슷한 소리의 낱말도 함께 찾는다).
   - 찾으면 강사의 설명으로 답하고, **어느 강의 몇 분 몇 초인지 링크와 함께** 준다. 근거 줄의 시각 링크를 그대로 쓰고 시각을 새로 만들거나 보정하지 않는다.
   - 여러 강의에 있으면 모두 적는다. 강사의 말을 일반 신학으로 보충·수정·반박하지 않는다.
2. **1순위에 없을 때만 2순위로 간다.** 그때는 "첫열매들 강의에는 이 부분을 직접 다룬 대목을 찾지 못했다"고 먼저 밝힌다.
   - 스코필드·무디·라킨·럭크만의 해설 가운데 **첫열매들 교리에 가장 가까운 것**을 고르고, 교리와 어긋나는 부분은 쓰지 않거나 어긋난다고 표시한다.
   - **출처를 반드시 붙인다**(해설가·책·장절/쪽·URL). 출처를 실제로 확인하지 못한 인용은 쓰지 않는다. 기억으로 인용을 지어내지 않는다.
   - 2순위 해설은 교회의 가르침으로 소개하지 않는다. "외부 해설(2순위)"임을 드러낸다.
3. **1·2순위로 부족하면 3순위**(이이레 목사 「다윗의 삶」)에서도 찾는다. 사무엘상·하 본문은 3순위 스크립트에 직접 해설이 많으므로 함께 확인하고, 1순위와 어긋나면 1순위를 따른다. 출처는 1순위와 같은 형식으로 준다.
4. 1·2·3순위 어디에도 없으면 없다고 말한다. 추측으로 메우지 않는다.

## 3. 성경 본문

- 답에 성경 구절을 적을 때는 README §3의 기본 역본 규칙(표준킹제임스성경, `node tools/kjv.mjs`, 글자 그대로)을 따른다. 자막에 들린 구절을 성경 본문으로 옮기지 않는다.

## 4. 교재 집필과의 관계

- 교재(PDF·EPUB)의 내용 규칙은 각 시리즈 지침과 README §3("내용은 강의와 교회 교재에서만")이 정한다. 이 문서는 **해석 질문에 대한 답**의 근거 순위다.
- 2순위 해설을 교재에 넣을지는 사용자가 따로 지시할 때 시리즈 지침을 먼저 고친 뒤 정한다.
