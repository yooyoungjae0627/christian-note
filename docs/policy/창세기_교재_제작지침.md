# 창세기 장별 교재 제작 지침

> ⚠ **2026-10-12부터 [장별 해설서 제작지침(2판)](장별해설서_제작지침.md)이 이 문서를 대신한다.** 이 문서는 1판(창세기 1–10장·사무엘상 1–15장 1판) 제작 기록으로만 남긴다.

2026-10-10 사용자 지시: 창세기 1–50장은 장마다 개별 PDF와 EPUB으로 집필한다. 1–3장을 먼저 제작해 GitHub에 푸시했다.

2026-10-11 사용자 지시: 이 지침대로 4–10장을 제작해 푸시한다. 승인 범위는 1–10장이며 11장 이후는 추후 요청 때 작업한다.

## 근간과 자료

- README가 지정한 밀크 교리 총정리와 공통 집필 정책을 근간으로 한다. 내용은 첫열매들 강의·교재에서만 가져온다.
- 1–3장은 기존 `창세기_1-3장_해설.pdf`의 해설을 출처 PDF와 다시 대조한다. 원고의 오류를 그대로 재사용하지 않고 근거와 수정 이유를 남긴다.
- 4장부터는 기존 해설 원고가 없다. Theme·Milk 전페이지 색인(`Genesis/자료검토/전체_PDF_본문색인.json`)에서 그 장의 근거 쪽을 찾아 해설을 새로 쓰고, 각 문단의 근거 원문을 해당 쪽 글자 그대로 `excerpt`에 보존한다(검사기가 쪽 글자와 대조). 교재가 그 절을 직접 풀이한 문단과 교재의 교리를 그 절에 연결한 문단(`basis: linked`, 출처 줄에 `관련 교리 연결`)을 구분한다. 근거가 없는 절은 `해설 미수록`으로 남긴다.
- Theme 33권과 Milk 11권 전체를 자료 검색 범위에 포함한다. 전페이지 색인·권별 요약 검토와 실제 채택 문단의 맥락 대조를 구분해서 기록한다.
- 성경 본문은 `tools/kjv.mjs`로 받은 표준킹제임스성경 한영대역의 글자를 그대로 쓴다. 출처는 `· 표준킹제임스성경`으로 적는다.
- 해설이 없는 대목을 일반 신학으로 채우지 않는다. 강의의 직접 풀이와 다른 교리를 연결한 설명을 구분한다.
- 근거 강의마다 설명이 다른 곳은 임의로 합치지 않는다. 근간과 해당 강의의 맥락을 대조하고 확인 사항을 기록한다.

## 출처와 구간 이동

- 모든 해설에 강의명·PDF 파일명·PDF 쪽수를 적는다. 관련 구절의 본문 위치도 함께 남긴다.
- 구간 점프가 없는 PDF도 유용하면 사용한다. 링크 유무로 자료를 제외하지 않는다.
- 원래 PDF의 확인된 구간 주소만 재사용한다. 이미 보정된 주소에 다시 3초를 빼지 않는다. 같은 페이지의 링크라도 해설 내용과 관계가 있는지 대조한다.
- 영상 재생으로 발언 시점을 확인하지 않았다면 이를 확인했다고 보고하지 않는다. PDF에는 QR·▶ 시각·클릭 안내, EPUB에는 ▶ 시각 링크를 넣는다.
- 각 문단의 근거 원문·파일·쪽수·링크 출처·연결 판단을 장별 JSON에 보존한다. 채택 근거가 약하면 재대조하거나 해설을 근거가 확인되는 범위로 수정한다.

## 구성과 디자인

- 한 장 = 한 권, 각각 `Genesis/창세기_01장_교재.pdf`와 같은 이름의 `.epub`. 여러 장의 합본을 만들지 않는다.
- 표지 → 읽는 법 → 차례 → 해당 장의 절 순서 본문·해설 → 한눈에 보는 이야기 → 개념 문제 → 답안 → 예상 질문과 답변 → 용어 풀이 → 참고 자료.
- 강의별 책과 달리 절 순서를 따른다. 원 강의 표제 쪽과 「들어가며」는 넣지 않는다. 이는 사용자가 요청한 장별 해설서 형식에 따른 적용이다.
- 2026-10-10 후속 사용자 지시: 바탕화면의 `창세기_1-3장_해설.pdf`를 디자인 기준으로 삼는다. 폰트·자간·줄간격·카테고리 간격·배경색 범위와 위치까지 이 PDF에 맞춘다. 기존 임의의 폰트 대체와 색상·배치보다 이 지시가 우선이다.
- A5(148×210mm), 여백 위 16·아래 19mm, 안쪽 16·바깥 14mm를 좌우 쪽에 교대로 적용한다. 본문 Noto Serif KR 10.3pt·줄간격 1.86, 제목 Noto Sans KR. 기준 PDF의 말씀 상자·인용 상자·금색 표제선과 강조 범위를 추출해 적용한다. 측정 기록은 `Genesis/원본/reference_style.json`에 보존한다.
- 표지는 남색→금색 그라데이션과 금색 테두리, 장의 내용을 상징하는 선 그림, 흰 제목, 하단 `성도 유영재 교재`. 십자가·하나님 얼굴·사람 얼굴은 그리지 않는다. 1–3장은 기준 PDF의 나무 그림, 4장부터는 장마다 다른 선 그림(`Genesis/원본/cover_art.py`)과 그 장 해설 문장의 표어를 쓴다.
- 강조는 노란 바탕 / 노란 바탕+굵게 / 노란 바탕+굵게+빨간 밑줄의 세 단계. 성경 글자를 바꾸지 않는다.
- 본문 단락은 이어 흐르게 하고 제목과 첫 내용, 출처와 관련 문단, 그림과 캡션을 묶는다. 긴 묶음은 본문 폭·글자 크기를 줄이지 않고 분할한다.
- 앞부분과 뒷부분은 새 쪽. 요약 12–22항목, 문제 25–41개, 예상 질문 12–14개. 문제·답·풀이도 채택한 해설과 원 교재에서만 만든다. 4장부터의 학습 자료는 장별 JSON의 `learning`에 둔다(1–3장은 `chapter_extras.py`).
- 이번 스타일 수정의 EPUB은 PDF의 폰트·색상 범위·위치가 그대로 유지되는 고정 배치로 제작한다. 페이지 이미지와 같은 위치의 링크를 보존하고, 텍스트 원문도 함께 담아 본문 대조를 가능하게 한다.

## 검증과 전달

- 장별 절 전체, 한영 본문 글자, 해설 누락, 모든 출처 쪽수·원문·기존 링크를 실제 검사한다.
- 모든 PDF QR을 실제 판독한다. 내부 목차 이동·EPUB XML·nav·ncx·내부 링크·리더 열기를 검사한다.
- PDF 전페이지를 렌더링해 시각 검수한다. 종료 코드·검사 수치·실패 원문을 기록하고 완료 보고한다.
- 완성 PDF·EPUB과 재생성에 필요한 원고·도구·검토 기록을 커밋한다. 캐시·임시 렌더링·node_modules를 커밋하지 않는다.
- 요청 범위의 검증본을 GitHub에 푸시한다. 바탕화면에는 같은 완성본을 복사한다.

## 변경 이유

샘플 한 권에서 장별 정식 교재로 작업 범위가 바뀌었다. 기존 샘플의 디자인을 공통 정책에 맞추고, 링크 없는 자료의 출처 및 해설 근거 기록을 유지한다.

2026-10-11: 4–10장 제작 지시에 따라 범위를 1–10장으로 넓혔다. 4장부터는 대조할 기존 해설 원고가 없으므로, 일반 신학으로 채우지 않도록 근거 원문 보존·쪽 글자 대조 검사·직접 풀이/교리 연결 구분 규칙을 추가했다.
