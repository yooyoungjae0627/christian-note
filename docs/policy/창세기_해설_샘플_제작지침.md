# 창세기 해설 샘플 제작 지침

> 과거 샘플 제작 기록이다. 2026-10-10부터 정식 장별 제작 규칙의 단일 원본은 [창세기 교재 제작 지침](창세기_교재_제작지침.md)이다. 아래는 이전 샘플의 작업 범위를 보존한 것이다.

2026-10-10 사용자 승인: 창세기 1-50장 해설서의 형식을 검토하기 위해 1장만 PDF와 EPUB으로 제작한다.

- 기존 바탕화면 `창세기_1-3장_해설.pdf`의 1장 본문과 해설을 바탕으로 한다.
- 강의별 교재와 달리 성경 본문 순서로 여러 교회 자료를 모은 해설서이다. 사용자의 요청에 따른 별도 형식이며 Theme 강의별 교재를 합치거나 수정하지 않는다.
- 근간은 README가 지정하는 교리 총정리와 공통 집필 지침이다. 일반 신학으로 내용을 보충하거나 수정하지 않는다.
- 창세기 1:1-31을 표준킹제임스성경 한영대역에서 가져오고 글자 그대로 싣는다. 자료에서 풀이를 찾지 못한 단락은 그대로 표시한다.
- 해설 문단 아래에 실제 출처의 강의명, PDF 쪽수, 확인된 유튜브 구간 링크를 표시한다. PDF에는 QR도 넣는다. 링크가 없는 출처에는 시점을 추정해 달지 않는다.
- 구간 점프가 없는 PDF도 해설의 근거로 쓸 만한 내용이 있으면 사용한다. 링크 유무로 제외하지 않고 강의명·PDF 파일명·쪽수를 반드시 적는다(2026-10-10 사용자 지시).
- 구간 링크는 출처 PDF에 실린 기존 주소를 그대로 재사용한다. 이를 영상에서 문장이 시작하는 초 단위 시점까지 확인했다는 의미로 표현하지 않는다.
- 각 해설의 원본 위치, 근거 인용문, 출처 쪽수, 링크와 연결 판단을 원본 JSON에 남긴다.
- A5 판형, 남색과 금색, 읽기 편한 한글 글꼴을 사용하고 표지는 '성도 유영재 교재'로 표기한다.
- 작업 원본과 결과는 `Genesis/`에 보존한다. 임시 렌더링과 런타임은 저장소 밖에 둔다.
- 본문 일치, 근거 연결, PDF 링크, 모든 QR 판독, EPUB 내부 연결, 렌더링을 실제 검사하고 exit code와 수치를 보고한다.

## 변경 이유

기존 해설서는 여러 자료를 모았다는 이유로 영상 이동을 생략했다. 이번 샘플은 이미 존재하는 근거 기록과 출처 PDF의 구간 링크를 연결하여 독자가 해설의 근거를 직접 확인하도록 한다.
