# memory-bank — 성경 해석의 근거 자료

성경 해석 질문에 답할 때 찾아보는 자료를 모은다. 순위와 쓰는 법은 [성경 해석 지침](../docs/policy/성경해석_지침.md)이 단일 원본이다.

| 순위 | 자료 | 위치 |
|---|---|---|
| 1순위 | 첫열매들 교회 영상 강의(박진영) — 재생목록 4개 104편(스크립트 89편) | [첫열매들_강의스크립트/](첫열매들_강의스크립트/) |
| 2순위 | 세대주의 해설(스코필드·무디·클라렌스 라킨·피터 럭크만) | 저장소에 없음 — 답할 때 출처를 직접 확인 |
| 3순위 | 서울침례교회 이이레 목사 「다윗의 삶」 59편 | [../사무엘상·하/강의스크립트/](../사무엘상·하/강의스크립트/) (목록 [../사무엘상·하/README.md](../사무엘상·하/README.md)) |

- **새 강의 추가 절차:** 「메모리 뱅크 업데이트」 명령은 스크립트 추가·푸시와 함께 그 강의의 책(PDF+EPUB)까지 만들어 푸시하는 한 묶음이다 — 규칙 원본은 [README §3](../README.md).
