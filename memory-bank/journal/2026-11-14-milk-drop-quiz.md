# 2026-11-14 밀크 1~10강(11권) 개념 문제·답안 삭제

## 사용자 지시
- 차례 캡처(「개념 문제 67 / 답안 69」)와 함께 「개념 문제 답안 전체 밀크 삭제해라」.

## 한 일
- 지침 먼저: `docs/policy/밀크교재_제작지침_1_전체판.md` §2·§5·§6·§7·§8에서 개념 문제·답안을 빼고 §10 바뀐 내력 신설. 주제별 도구 README의 「밀크만 예외」 문구도 고침.
- 밀크는 원고가 저장소에 없어 완성 PDF를 직접 고치는 도구 `tools/milk_drop_quiz.mjs`를 새로 씀.
  - 두 단원 쪽 삭제 → 뒤쪽 쪽 번호(DejaVuSans 글리프)를 지운 쪽 수만큼 당김.
  - 차례: 두 줄의 글리프·링크·이름 목적지(quiz·answers) 삭제, 아래 두 줄(예상 질문과 답변·용어·인물 풀이)을 그 자리로 올리고 쪽 번호 글리프를 바꿈(같은 Type3 글꼴의 숫자).
  - 「이 책을 읽는 법」: 「개념 문제, 」「답안, 」「개념 문제(답안은 다음 쪽부터) →」 글리프를 지우고 뒤 글자를 당김(재조판 없음 — 그 줄만 조금 짧아짐).
- EPUB은 새 PDF에서 `pdf2epub.mjs`로 다시 만듦.
