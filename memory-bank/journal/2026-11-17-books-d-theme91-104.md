## 배운 것
- EPUB은 sparse-checkout 규칙 밖이라 `git add`가 조용히 멈춘다 → `git add --sparse`로 넣고, 커밋이 실제로 생겼는지 `git log`로 확인.
- center_fit.mjs `--lum N`은 파일 인자 **뒤에** 써야 한다(앞에 쓰면 값이 파일 이름으로 읽힘) — 도구 버그.
- 저장소 위치에서 check_story(sharp)·check_epub(jszip)를 돌리면 모듈을 못 찾아 exit 1 → %TEMP%\topicbook_d 아래 tools 사본에서 돌려야 함 — 하네스 개선 대상.
- 화이트보드를 평탄화하면 연한 마커 획이 지워짐 → 정확한 16:9 영역만 잘라 원본 밝기 유지.
- 유튜브 video 요소가 중간에 바뀜 → 스캔 매 단계마다 document.querySelector('video')를 다시 잡고 길이는 p.getDuration().
- 세션이 다시 시작되면 브라우저 IndexedDB·수신기가 날아갈 수 있음 → 뜬 프레임은 바로 옮기고, 묶음 목록(localStorage)으로 다시 뜰 수 있게 해 둠.
- 반투명 띠 자막(98·104)은 띠 위아래로 화이트보드·벽의 가로선이 비친다 → %TEMP%\topicbook_d\hline.mjs: 글자 영역 위·아래에 있는 얇고 긴 덩어리만 지운다(글자 영역 안까지 지우면 「드」의 ㅡ 획이 사라졌다).
- 워크플로 수정 단계가 녹취의 못 알아들은 말을 그럴듯한 강의 이름(「신약 개관」)으로 채운 일이 있었다 → 커밋 전 원고에서 「추정」을 찾아 보고, 지어낸 이름은 빼고 다시 빌드했다.
