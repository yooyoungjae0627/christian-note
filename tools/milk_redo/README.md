# 밀크 슬라이드 그림 다시 따기 (2026-11-14~)

사용자 지시 「밀크 pdf도 강의 ppt에 대해서 정책에 따라 수정해라」 — 주제별 지침 §0(2026-11-14) 방식:
스크린만 원근 보정해 1920×1080으로 펴고, 여러 프레임 화소별 중앙값으로 강사를 지운 그림.
밀크는 원고가 없어 완성 PDF 안의 그림만 `tools/milk_replace_slides.mjs`로 바꾼다.

사용자가 고른 받기 방법: 저화질(360p, 형식 134) 전체 + 1080p(형식 299)는 고른 구간만 `yt-dlp --download-sections`.

## 순서 (책 하나, 작업 폴더 `%TEMP%\milkredo`, node_modules는 `%TEMP%\topicbook`)
1. 옛 그림 뽑기 → `%TEMP%\milkimg\mN_pPPP_객체번호_WxH.png` (옛 그림 = 무대 전체 프레임을 거의 그대로 줄인 것)
2. `reg.mjs` — FIRSTFRUITS 로고로 옛 그림 ↔ 1080p 프레임 좌표(축척·이동).
3. 360p 1초 프레임 `scan/mN/%05d.jpg` (ffmpeg fps=1, 640×360).
4. `windows.mjs` — PDF ▶ 시각으로 그림마다 찾을 구간. `seg.mjs` — 그 구간에서 같은 슬라이드인 무대 화면 시각.
5. `pick.mjs` — 강사 위치가 겹치지 않는 4초 창 8개. `dl.sh` — 1080p 구간 받기(병렬).
6. `crop.mjs` — 프레임(초당 1장) 중 같은 슬라이드만 골라 `screen_crop.mjs --check`로 펴고 중앙값.
7. 한 장씩 눈으로 확인(슬라이드 번호가 옛 그림과 같은지, 강사 잔상) → `milk_replace_slides.mjs` → `pdf2epub.mjs` → `check_epub.mjs`.

무대 스크린 모서리(1080p, 밀크 1~3강에서 확인): `397,67,1918,63,1918,955,397,957`.

## 알려진 함정
- 그림은 같고 글만 다른 슬라이드(1강 33·34번)는 전체 비교로 섞인다 → 글 쪽 절반만 비교해 구간을 가른다.
- 4강 53쪽처럼 가까운 카메라로 딴 옛 그림은 로고 맞춤이 실패한다(rms 80) → 따로 찾는다.
- 사진이 스크린 끝까지 찬 슬라이드는 `--check`가 exit 2(가장자리 화소)를 내지만 정상 — 눈으로 확인.
- yt-dlp를 많이 부르면 YouTube가 「Sign in to confirm you're not a bot」으로 막는다(2026-11-15 05:50쯤부터). 막힘을 우회하지 않고 풀릴 때까지 기다린다.
