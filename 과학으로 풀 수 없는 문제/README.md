# 과학으로 풀 수 없는 문제

> **EPUB 제작 중단(사용자 지시 2026-11-21):** 이 문서의 EPUB 관련 서술(PDF + EPUB, build_epub·verify_epub·check_epub 등)은 효력이 없다. 완성본은 PDF 하나만 만든다 — 단일 원본 `docs/policy/로컬_EPUB_보관정책.md`.

사용자 제공 영상·자막을 묶어 읽는 로컬 PDF 시리즈입니다. 현재 책은 **과학적으로 풀 수가 없는 난제**이며 아래 세 카테고리를 담습니다.

1. 존재 자체가 미스테리인 행성, 해왕성
2. 과학자들이 신의 존재를 부정할 수 없는 이유
3. 지구에 '산소'가 있다는 게 기적과도 같은 이유

1번 [해왕성 영상](https://www.youtube.com/watch?v=U5eVzn6bx2I)과 3번 [산소 영상](https://www.youtube.com/watch?v=whHsl0w9abw)은 코덱스의 숨겨진 백그라운드 브라우저(음소거)에서 직접 열어 캡처합니다. 2번은 링크가 제공되지 않았으므로 자막만으로 집필하고 영상 캡처를 요구하지 않습니다. 캡처 원본은 각 주제의 `screenshots/raw/`에 보존합니다. 해왕성 인쇄용은 하단 11%만 잘라 자막띠·재생바를 제거했으며, 각 주제의 원본·인쇄용 크기, 잘라낸 범위와 실제 시각은 해당 `screenshots/manifest.json`에 기록합니다.

기존 집필 정책의 쉬운 한국어·주제별 강조·원문 보존·문제와 답안·예상 질문·출처 확인을 적용합니다. 이 자료는 첫열매들 예배 강의가 아니므로 교회 강의로 표기하거나 제공되지 않은 성경 본문을 덧붙이지 않습니다. 자막의 논지와 공식 자료로 확인한 보충은 구분합니다. 모든 미해결 문제가 영원히 과학적으로 불가능하다거나 모든 과학자가 유신론자라는 뜻으로 제목을 해석하지 않습니다.

이 책은 2026-11-16 사용자 지시에 따라 **A4 세로**로 편집합니다. 본문과 답안은 15pt 이상, 도식 설명은 12pt 이상으로 유지하며, 캡처는 원래 비율 그대로 본문 전체 폭에 넣습니다. 제목과 부제는 단어 단위로 줄바꿈하고, 문단이 다음 쪽으로 이어지면 차례·본문 근거 링크의 실제 쪽수를 다시 계산합니다. 각 쪽의 자료 출처와 용어 풀이는 본문과 분리합니다. 산출물은 PDF이며 EPUB은 만들지 않습니다. 기존 공통 정책 문서는 바꾸지 않습니다.

## 원본과 재현

- `원본/해왕성/transcript_raw.txt`: 받은 자막 원문
- `원본/해왕성/screenshots/`: 직접 영상 캡처
- `원본/신의 존재/transcript_raw.txt`: 받은 자막 원문
- `원본/산소/transcript_raw.txt`: 세 번째 영상의 자막 원문
- `원본/산소/screenshots/`: 세 번째 영상의 직접 캡처
- `원본/원고.md`: PDF와 같은 내용의 집필 원고
- `원본/tools/book_data.py`: 원고·문제·참고자료 데이터
- `원본/tools/oxygen_data.py`: 세 번째 카테고리의 추가 원고·문제·참고자료
- `원본/tools/build_book.py`: PDF 생성기

reportlab·Pillow·PyMuPDF가 있는 Python을 사용합니다. 저장소 안에 라이브러리를 설치하지 않습니다. 작업용 렌더와 검사 결과는 저장소 밖 임시 폴더에 보관합니다. 검수 후 완성 PDF를 로컬 저장소와 바탕화면에 갱신하고, 이 폴더의 원고·캡처·도구·PDF를 GitHub `main`에 커밋·푸시합니다.

## 빌드와 검사

위 패키지를 사용할 수 있는 Python 실행 파일의 절대 경로를 `$pythonExe`에 지정한 뒤, 저장소 루트에서 실행합니다.

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
$env:PYTHONIOENCODING = 'utf-8'
$qaDir = Join-Path $env:TEMP 'science-book-portrait/qa'
& $pythonExe -B '과학으로 풀 수 없는 문제/원본/tools/build_book.py' --qa-dir $qaDir
& $pythonExe -B '과학으로 풀 수 없는 문제/원본/tools/verify_book.py' --qa-dir $qaDir
```

생성기는 1차 조판의 실제 위치로 차례·답안 링크를 갱신하고 쪽수가 안정되면 PDF를 내보냅니다. `layout.json`에는 장별 실제 쪽과 캡처 위치가 기록됩니다. 검사기는 전체 본문·문제·답안·FAQ·출처·교정 내용, 15pt 본문, 12pt 도식, 세로 판형, 내부 링크, 잘림·텍스트 겹침, 캡처 20장의 원본 화소 일치를 확인합니다. `verification.json`과 쪽별 PNG·컨택트시트를 함께 확인합니다.
