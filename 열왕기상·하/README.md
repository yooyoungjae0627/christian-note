# 열왕기 — 열왕기상·하 이야기 단원별 교재 (2판)

성도 유영재 교재. 2026-10-23부터 사무엘상·하와 같은 정책으로 **이야기 단원마다 PDF·고정 배치 EPUB 한 권**을 낸다. 권(열왕기상·열왕기하)별로 따로 번호를 매긴다(`열왕기상_NN_<단원 제목>`, `열왕기하_NN_<단원 제목>`). 단원 책마다 본문 앞에 「소설로 먼저 읽기」(성경 구절에 기반한 이야기)를 싣는다.

- 규칙: [장별 해설서 제작지침(2판)](../docs/policy/장별해설서_제작지침.md) §0-3(열왕기), §2-4(소설로 먼저 읽기). 근거 순위: [성경 해석 지침](../docs/policy/성경해석_지침.md).
- 장별 원고: [원본/2판/](원본/2판/) (`1ki-NN.json` 22장, `2ki-NN.json` 25장, 본문 `verses-1ki.json`·`verses-2ki.json`, 현대 영어 `verses-*-web.json`).
- 단원 목록·원고: [원본/단원/](원본/단원/) (`units-1ki.json`, `units-2ki.json`, `1ki-unitNN.json`, `1ki-novelNN.json` …).
- 다시 만들기: [tools/chapterbook/README.md](../tools/chapterbook/README.md) — `units.mjs 1ki make|check`, `novel.mjs 1ki check`, `build.mjs 1ki unit N`, `verify.mjs 1ki unit N`.
- 근거: 열왕기에는 3순위(이이레 「다윗의 삶」)가 59편(열왕기상 1장)뿐이다. 1순위(첫열매들 영상·교회 교재)와 2순위(스코필드 관주 해설 1917)를 주로 썼고, 근거를 찾지 못한 단락은 `해설 미수록`으로 두었다.
- 근거 비율(2026-10-24): 열왕기상 1순위 104(직접 24·연결 54·교리 적용 26) · 2순위 55 · 3순위 23(1·2순위 87.4%), 해설 미수록 단락 7/121. 열왕기하 1순위 99(직접 12·연결 51·교리 적용 36) · 2순위 99 · 3순위 0(1·2순위 100%), 해설 미수록 단락 4/140. 1순위 가운데 연결·교리 적용이 많다(강의가 그 왕·사건을 직접 풀이하지 않은 곳) — 검수 거리는 [journal](../memory-bank/journal/2026-10-24-kings-story-units.md).
